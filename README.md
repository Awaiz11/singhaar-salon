# Singhaar Salon (concept)

A concept website for a women-only beauty salon in Model Town, Lahore. Designed and built by NexaFlow with Next.js.

- A mehndi mandala that draws itself in the hero
- Services and prices in tabs (makeup, hair, mehndi, skin, nails)
- Bridal packages compared side by side
- Booking by day and time, or by wedding date for brides, sent to WhatsApp

Live: https://singhaar-salon.vercel.app/
